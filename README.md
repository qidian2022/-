# 稳稳过 科目一练习 @qi_dian

电脑浏览器优先的科目一练习网页，提供一层导航：全量题库（1841 道）、C1/C2 精简（300 道原题精选）和我的收藏。精选题是全量题库的子集；同一道题在两个入口共用答题记录和收藏，答错题自动进入“我的收藏”。

全量题库保留原选项、解析和题图。精选文件保留 300 道原题的题干、选项、答案、原题号、链接与配图，未收录逐题解析；精选练习中的解析位置显示“暂无解析”。

## 使用

在 macOS 上可双击 `启动刷题网页.command`，它会启动本地网页服务并打开浏览器。运行期间请保持弹出的终端窗口开启。**不要直接双击 `index.html`**；那是应用入口文件，不能用 `file://` 地址运行。

也可以在终端运行：

```bash
npm ci
npm run dev
```

打开终端显示的本地地址。答对后显示反馈约 1 秒并自动进入下一题；答错后停留在当前题看答案，同时自动收藏。答题记录、随机题序与收藏保存在当前浏览器。同一道精选题在两个入口共享答案：在精选页“重新开始”会清空这 300 道题的答案，在全量或收藏页重新开始会清空全部答案，收藏始终保留。首次启用新题库会清除旧版答题记录，保留全量题库原有的收藏。

## 开发与检查

```bash
npm test
npm run build
```

`npm run dev` 和 `npm run build` 会从 `data/题库.md` 及 `data/科目一_C1C2_原题精选300.md` 生成网页用的 JSON。转换时逐题核对精选文件与原题的题干、选项、答案、来源链接和配图，并确认 300 道题全部属于网页全量题库。原题 342 按要求恢复；原题 341、3554、3555 仍从网页排除。生成文件位于 `src/generated/`，无需手动编辑。

## 发布

推送到 `main` 后，GitHub Actions 会构建并部署到 GitHub Pages。首次发布时，在仓库 Settings → Pages 中将 Source 设为 **GitHub Actions**。部署构建会根据 GitHub 仓库名称设置资源路径；仓库 `qidian2022/kemuyi-practice` 对应 `/kemuyi-practice/`。
