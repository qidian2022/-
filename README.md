# 稳稳过 科目一练习 @qi_dian

电脑浏览器优先的科目一练习网页，提供一层导航：全量题库（1840 道）、C1/C2 精简（298 道）和我的收藏。两个题库独立练习，两个来源的手动收藏和答错题统一显示在“我的收藏”。精简题库的来源计划稍后更换；目前仍使用原来的问答文件。

全量题库保留原选项、解析和题图。精简文件只有问答，没有选项或逐题解析；程序从同一文件的其他答案中自动组合练习选项。精简题答题后显示原文件参考答案，这些选项不是官方考试原题。

## 使用

在 macOS 上可双击 `启动刷题网页.command`，它会启动本地网页服务并打开浏览器。运行期间请保持弹出的终端窗口开启。**不要直接双击 `index.html`**；那是应用入口文件，不能用 `file://` 地址运行。

也可以在终端运行：

```bash
npm ci
npm run dev
```

打开终端显示的本地地址。答对后显示反馈约 0.4 秒并自动进入下一题；答错后停留在当前题看答案，同时自动收藏。答题记录、随机题序与收藏保存在当前浏览器；在全量或精简页点“重新开始”只重置当前题库，在收藏页点此按钮则重置两个题库的答题记录，收藏始终保留。

## 开发与检查

```bash
npm test
npm run build
```

`npm run dev` 和 `npm run build` 会从 `data/题库.md` 及 `data/科目一_C1C2_300题精简题库.md` 生成网页用的 JSON。转换过程检查原始题目数量、答案、题图路径、重复题号和精简题选项，再排除两道相互矛盾的题干在原题库中的 4 条记录和精简题库中的 2 条记录。源文件不作修改；生成文件位于 `src/generated/`，无需手动编辑。

## 发布

推送到 `main` 后，GitHub Actions 会构建并部署到 GitHub Pages。首次发布时，在仓库 Settings → Pages 中将 Source 设为 **GitHub Actions**。部署构建会根据 GitHub 仓库名称设置资源路径；当前仓库 `qidian2022/-` 对应 `/-/`。
