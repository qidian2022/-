# 稳稳过 · 科目一刷题

电脑浏览器优先的科目一练习网页，可切换两个题库：1844 道全量题和 300 道 C1/C2 精简题。两者都有即时对错反馈与本地收藏，答题进度互不影响。

全量题库保留原选项、解析和题图。精简文件只有问答，没有选项或逐题解析；程序从同一文件的其他答案中自动组合练习选项。精简题答题后显示原文件参考答案，这些选项不是官方考试原题。

## 使用

在 macOS 上可双击 `启动刷题网页.command`，它会启动本地网页服务并打开浏览器。运行期间请保持弹出的终端窗口开启。**不要直接双击 `index.html`**；那是应用入口文件，不能用 `file://` 地址运行。

也可以在终端运行：

```bash
npm ci
npm run dev
```

打开终端显示的本地地址。答对后显示反馈约 0.4 秒并自动进入下一题；答错后停留在当前题看答案，同时自动收藏。答题记录、随机题序与收藏按题库分别保存在当前浏览器；“重新开始”只重置当前题库的答题记录并重新排题，收藏会保留。

## 开发与检查

```bash
npm test
npm run build
```

`npm run dev` 和 `npm run build` 会从 `data/题库.md` 及 `data/科目一_C1C2_300题精简题库.md` 生成网页用的 JSON。转换过程检查题目数量、答案、题图路径、重复题号和精简题选项。生成文件位于 `src/generated/`，无需手动编辑。

## 发布

推送到 `main` 后，GitHub Actions 会构建并部署到 GitHub Pages。首次发布时，在仓库 Settings → Pages 中将 Source 设为 **GitHub Actions**。部署构建使用 `/kemuyi-practice/` 作为资源路径。
